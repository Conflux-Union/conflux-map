# Conflux Map

[English](README.md) | **简体中文**

Conflux Map 是一个 Fabric 客户端小地图 / 世界地图模组。

## 亮点

- **全图同步 + 共享路径点。** 消除地图黑块。新玩家进服即可查看实时全服地图，
  机器和建筑均可从公共路径点获取坐标，无需逐个手动添加。
- **极低流量消耗。** 通过预测地图 + 权威地图、瓦片分块、增量更新和更紧凑的数据结构，
  将一次地图同步的数据量控制在数百 B 至数百 KB。
- **单一客户端 JAR。** 无需分别安装小地图、世界地图、群系预览、区块加载状态地图、
  地图同步和路径点同步等多个 Mod；一个 Conflux Map 客户端 JAR 已经覆盖绝大多数
  地图 Mod 的常用功能。

## 功能特性

- **小地图 HUD：** 支持方形或圆形外观、64 至 256 像素尺寸、四档缩放、自由拖放和
  跟随视角旋转。信息栏可显示坐标、生物群系和当前图层；打开背包等界面时会自动避让，
  并为 JEI/REI 的悬浮面板留出空间。
- **全屏地图：** 使用多分辨率瓦片保存和显示地图，支持连续缩放、拖动浏览、区块网格
  和以光标为中心缩放。右键点击地图即可创建路径点、分享坐标，或在有权限时直接传送。
- **三种基础图层：** 可在普通地形、固定配色的群系地图和服务端区块加载状态之间切换。
  区块加载状态既可按直观分带显示，也可查看精确的加载票等级。
- **维度切层显示：** 主世界自动识别地表和洞穴，下界可在当前层与基岩顶层之间切换，
  末地使用适合虚空环境的地图背景。地表图层还会根据昼夜和光照调整明暗。
- **种子预览：** 获得世界种子后，未探索的主世界和末地区域会直接显示预测的生物群系、
  地形高度和树木。玩家探索或服务端返回真实地形校正后，权威地图会逐步覆盖预测结果；
  超平坦世界同样支持预览。
- **结构筛选器与搜索：** 覆盖当前游戏版本在主世界、下界和末地中的原版结构集合。
  每种结构均有独立图标和显示开关，预测位置与服务端确认位置使用不同边框，搜索功能可
  直接跳转到最近的候选位置。
- **种子预览范围：** 按 `P` 可在全部区域、仅服务端已生成区域和仅玩家访问区域之间
  切换。需要查看纯权威地图时，可以关闭未探索区域的预测内容。
- **按服务器区分世界档案：** 面对代理网络或同一地址背后的多个世界时，通过地形指纹
  区分地图数据。世界档案支持创建、重命名和解绑，防止不同世界的地图记录混在一起。
- **公共路径点与聊天分享：** 服务端可维护一份供所有 Conflux Map 客户端查看的公共
  路径点列表；聊天坐标则可在所有服务器上使用，发送前会预览 Conflux Map 与 Xaero
  两种格式，收到后可一键导入。
- **本地路径点与死亡点：** 路径点支持名称、颜色、路径点集和显示状态，每个维度保留
  最近五个死亡点。主世界与下界之间还可按 8:1 坐标比例联动显示。
- **世界内路径点标记：** 路径点可以显示为光柱、名称和距离；小地图边缘会提示范围外
  目标的方向，地图标记也会说明目标位于玩家上方还是下方。各项显示距离可独立配置。
- **路径点集管理：** 支持创建、重命名和删除路径点集，也可以多选路径点或全选当前
  筛选结果，一次性迁移到其他集合。
- **从其他 Mod 导入：** 支持一键迁移 Xaero's Minimap 和 VoxelMap 路径点。自动跳过
  重复坐标，不影响原路径点文件。
- **地图绘图：** 支持直线、圆形、矩形、自由画笔、橡皮擦和文字标签。图形可以移动、
  改色和删除，并支持撤销与重做；每个图形可选择断线后清除或按世界和维度永久保存，
  也可以同步显示在小地图上。
- **近期足迹：** 最近 1 至 120 秒的移动路线可以用圆点显示在小地图和全图地图上，
  足迹时长、圆点大小和显示状态均可调整。
- **实体雷达：** 玩家、敌对生物、被动与中立生物，以及掉落物、载具和弹射物均有独立
  开关。图标使用对应的实体头颅或物品外观，密集目标会自动聚合，玩家标记始终单独显示。
- **PNG 导出：** 可以在地图上选择任意矩形范围或直接输入坐标，以每像素 1 至 16 个方块
  的分辨率导出 PNG。导出前会预估文件大小，并可选择是否包含地图绘图；任务在后台运行，
  支持查看进度和随时取消。
- **可选服务端组件：** Fabric 服务端使用对应版本的模组 JAR，Paper 1.21.1 至 26.2
  使用独立插件。管理员可以统一控制世界种子、真实地形校正、公共路径点、区块加载状态
  和实体雷达权限。
- **更新检查：** 可在启动时检查新版本，并在聊天中提供下载链接，同时在地图界面显示
  更新角标。
- **游戏内设置：** 客户端设置均可在游戏内调整并立即生效，滑块支持直接输入数值。
  安装 MaliLib 后可使用组合快捷键，并通过 A+C 配置界面管理 Conflux Map。

## 按键绑定

未安装 MaliLib 时，所有按键都可以在 Minecraft 原版按键设置界面的
"Conflux Map" 分类下重新绑定。安装 MaliLib 后，游戏内按键会迁移到 MaliLib
的热键界面（支持多键组合），并且在 Minecraft 1.21.1 及更高版本上，Conflux
Map 会注册进 MaliLib 的 A+C 配置切换界面。Minecraft 1.17.1 保留一个可选的
原版快捷键，因为它对应的 MaliLib 版本早于配置界面注册 API。

| 默认按键 | 功能 |
|---|---|
| `H` | 开关小地图 |
| `]` / `[` | 小地图放大 / 缩小 |
| `M` | 打开全屏世界地图 |
| `Y` | 切换手动图层模式 |
| `U` | 打开路径点列表 |
| `B` | 在当前位置新建路径点 |
| `J` | 显示或隐藏本地坐标点 |
| `,` | 打开设置界面 |
| `P` | 切换种子预览范围（全部 / 仅已生成 / 仅已访问） |
| `F9` | 刷新种子预览瓦片 |

## 路径点管理

路径点默认只在创建它的维度中显示。设置中提供一个默认关闭的开关，开启后主世界和
下界的路径点在两个维度中互相可见，显示时按 8:1 传送门坐标比换算；末地路径点始终
仅在末地显示。路径点列表支持创建、重命名和级联删除本地路径点集，也支持多选或
全选当前筛选结果后在集合之间批量迁移。

路径点也可以直接显示在世界里：一道光柱，名称和距离浮在上方。两部分可以分别关闭，
也可以设置多远之内才显示。屏幕上的路径点列表浮层暂未实现。

## 公共坐标点

公共坐标点要求服务端安装兼容版本的 Conflux Map，并且默认关闭。权限等级 2 的 OP 可以执行
`/confluxmap waypoints enable`、`disable` 或 `status`；配置会保存到
`config/confluxmap/server.json`。功能关闭或不可用时，客户端不会显示公共路径点按钮、
标签页、共享选项或相关设置。公共坐标点存储在世界目录中，对所有已连接的模组
客户端可见，发布后不可编辑。未锁定的公共点只能由发布者本人删除；OP 可以锁定、
解锁或删除任意公共点。
默认限制为每个世界 512 个、每位发布者 64 个，以及每位玩家每分钟 30 次修改。
管理员可在同一服务端配置中调整 `maxSharedWaypointsPerWorld`、
`maxSharedWaypointsPerPlayer` 和 `sharedWaypointMutationsPerMinute`。

聊天共享在所有服务器上均可使用。每次发送前都会原样预览将要发出的两条聊天消息
（Conflux Map 与 Xaero 两种格式）。
识别到 Conflux Map 格式或带 `X/Y/Z` 标签的消息时，聊天中会提供点击导入动作，并在
实际保存前打开本地坐标点编辑表单。

## 服务端 companion 策略

Fabric 服务端把对应版本的模组 jar 放入 `mods/`；Paper 服务端把
`confluxmap-paper-<version>.jar` 放入 `plugins/`。Paper 产物只支持 Paper API，
不支持 Folia、Spigot 或 CraftBukkit；客户端仍使用对应 Minecraft 版本的 Fabric jar。
运行方式和存储说明见 [Paper companion](docs/paper-companion.md)。

客户端与服务端版本不必完全一致。受支持的兼容下限是 v0.1.0：预测算法一致时继续
使用体积最小的差分数据，当前协议一致但预测算法不同时自动退回完整数据；遇到无法
确认的更老协议时，只关闭地图校正同步。共享路径点会单独协商双方都支持的最高次版本。
同步不可用时，客户端仍保留设置项和已保存的偏好，并显示服务端限制或版本不兼容的原因。

companion 共享的所有内容都在 `config/confluxmap/server.json` 中控制：

- `shareSeed`（默认 `false`）在客户端握手中附带世界种子。开启后，
  `allowBiomeMap` 和 `allowStructureSearch`（均默认 `true`）可分别控制合作
  客户端的全屏群系图层和结构图层 / 最近候选搜索，重启服务器后生效。
- `shareChunkLoadState`（默认 `false`）暴露服务端当前保持加载的区块。默认
  关闭，因为已加载区块会暴露玩家活动和长期运行的农场。
- `allowEntityRadar`（默认 `true`）控制合作客户端是否可以扫描并渲染实体雷达。
- `shareCorrections`（默认 `true`）提供真实地形地图校正。
- `shareWaypoints`（默认 `false`）启用共享路径点目录。

这些配置是客户端策略，不是反作弊。服务端一旦共享种子，修改过的客户端或外部
工具仍可自行推算相同的群系和结构数据，修改过的客户端也始终可以运行自己的
雷达。

地图同步的单玩家速率限制和带宽预算（`maxTilesPerRequest`、
`maxPendingTilesPerPlayer`、`maxBytesPerSecondPerPlayer`、
`minRequestIntervalMs`、`maxChunkSummariesPerSecond`）也在同一个文件中。任何
玩家都可以在游戏内执行 `/confluxmap performance`，查看自己连接的地图同步
耗时和流量统计。

## 构建

需要 JDK 21 或更高版本。其余的东西 —— Minecraft、映射表、Fabric API，以及 26.x
构建所面向的 JDK 25 工具链 —— 都由 Gradle 按需自动下载。

```sh
./gradlew :1.21.11:build
./gradlew :paper:build
./gradlew :paper:runServer
```

可将 `1.21.11` 替换为上面任一受支持的构建。构建产物输出到
`versions/<minecraft-version>/build/libs/`；独立 Paper 插件输出到 `paper/build/libs/`。
`:paper:runServer` 会下载并启动本地 Paper 1.21.1 开发服务器，同时安装刚构建的插件。
首次运行时需要阅读 Minecraft EULA，在 `paper/run/eula.txt` 中设置 `eula=true`，然后再次运行。
