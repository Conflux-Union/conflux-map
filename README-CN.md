# Conflux Map

[English](README.md) | **简体中文**

Conflux Map 是一个面向多人游戏的 Fabric 小地图 / 世界地图模组。它整合了小地图、世界地图、群系地图、区块加载票地图、结构查找器、路径点同步等功能为一个jar文件。且单次同步流量消耗仅在几百字节到几百kb。

## 安装

在 [Releases](../../releases) 页面下载对应 Minecraft 版本的 JAR（或参考下方[构建](#构建)自行编译），
放进 `mods/` 目录，同时安装 [Fabric API](https://modrinth.com/mod/fabric-api)。
[MaliLib](https://modrinth.com/mod/malilib) 是可选的，装上后可以用组合键绑定，Conflux Map 也会出现在
它的 A+C 设置切换界面里。

单机或普通原版服务器上，这份说明里的功能都能正常使用。服务端 companion（对应版本的 Fabric 模组
JAR，或 Paper 上的 `confluxmap-paper-<version>.jar`）是可选安装项，它的作用是把原本各玩家各自维护
的地图和路径点变成全服共享，见后面的[服务端 companion](#服务端-companion)。

## 功能特性

**地图。** 小地图支持方形或圆形、自由缩放、跟随视角旋转、随意拖放，还会在原版 HUD 元素挡到它时自动
临时避让；信息行可以显示坐标、当前生物群系和正在使用的图层。全屏地图支持连续缩放和区块网格，右键
点击即可创建路径点、把坐标分享到聊天或直接传送。两个地图都会跟随所在维度自动调整：主世界分地表和
洞穴，下界分当前层和基岩顶层，末地则使用专门适配虚空场景的背景。地表层默认会按昼夜和附近方块光照
着色，也可以关掉。

**显示模式。** 全屏地图的底图可以在「地图」「群系」「加载等级」三种模式之间切换，其中加载等级还能
选"状态分级"或"精确等级"两种精度。加载等级需要服务端装 companion；小地图只显示普通地形。

**地图补全。** 拿到世界种子后，未探索的主世界、下界基岩顶层和末地区域会立即显示预测的地形，不再是
一片黑。随着玩家探索或服务端返回校正数据，预测结果会逐步被替换成真实地图。按 `P` 可以在全部预测、
仅已生成区域和仅已探索区域之间切换。如果服务器不公开种子，可以在设置 → 地图补全 → 配置本地种子里
自己填一个：种子只留在本地，不会发给服务端，也不会因此开启地图同步。

**结构。** 主世界、下界、末地的原版结构都有各自的图标、分类显示开关和一个总开关。可以按名称搜索最近
的一处，也可以给定中心坐标、半径和结果数量，列出该范围内的所有候选点并直接把任意一个存成路径点。
预测位置和服务端确认位置会用不同的标记区分。

**路径点。** 本地路径点支持名称、颜色和分组；列表可以搜索、按分组过滤、批量选中并移动到其他分组；
世界中会显示光柱、名称和距离，视野外的点会在屏幕边缘用指示器提示，还可以设置一个显示距离上限；每个
维度会自动保留死亡点（默认 5 个，可在 0–50 之间调整）；还能一键导入 Xaero's Minimap 和 VoxelMap 的
路径点（自动跳过重复项，原文件不会被改动）。主世界和下界之间可以选择按 1:8 的传送门坐标比例互相
显示路径点。

**子世界。** 面对同一地址背后的多个服务器（比如代理网络）时，地图数据会按世界分开保存，不会把不同
服务器的地形混在一起。当模组无法判断当前是哪个世界时，会暂停地图记录并让你手动选择；同一个界面还
可以新建、重命名和清除识别记录，把种子相同的旧地图缓存合并进当前世界，以及把留在旧记录里的路径点
迁移过来。由 companion 直接识别出的世界，会按你给它起的名字显示，没起名时显示成编号，而不是内部
ID。

**服务器地址。** 同一台服务器有多个地址（简短别名、完整域名、纯 IP）时，它们现在共用一份地图缓存、
路径点和本地种子，而不是按你输入的地址各存一份。这个功能不需要 companion：只差大小写或末尾一个点
的地址会自动合并，其余的在子世界界面的「服务器地址」里手动关联或取消关联。显式写出的端口不会被当
成默认端口，因为 `mc.example.com` 和 `mc.example.com:25565` 可能连到不同的机器。服务端装了 companion
的话，它会直接告知这些地址指向同一个世界，就不用手动关联了。取消关联不会删除任何数据，只是从此之
后分开存放；已经存有自己地图数据的地址也不会被覆盖关联。

**绘图与足迹。** 可以在地图上画直线、图形、自由笔迹和文字标签；已经画好的内容可以选中移动、改色、
用可调大小的橡皮擦擦除，并用 `Ctrl+Z` / `Ctrl+Y` 撤销和重做。每份绘图可以选择永久保存或断线后清除，
也可以同步显示在小地图上。两个地图上都能显示最近一段时间的移动足迹。

**实体雷达。** 玩家、生物、掉落物、载具和弹射物各有独立开关。所有生物的头像都是从它自己当前的模型
实时生成的，所以新出的原版生物和模组生物都不需要额外贴图。小地图上默认不显示其他玩家，只有按住玩家
列表键（默认 Tab）时才会显示；全屏地图则始终显示。

**网页地图。** 服务端 companion 提供的可选浏览器地图，不需要装游戏模组。能看到跟客户端一样的已探索
地形和地形预测、共享路径点；如果管理员开启了对应选项，还能看到玩家位置和名字，另外支持切换维度和
界面语言。默认关闭且只监听本机地址，开启方式见[服务端 companion](#服务端-companion)。玩家可以用
`/confluxmap webmap hide` 把自己从网页地图上隐藏（`show` 恢复显示）。

**导出。** 可以把地图上任意区域导出成指定分辨率的 PNG：既能直接输入两个角的坐标，也能在地图上拉框
选择，可以选择是否包含绘图内容，导出前会估算文件大小。导出在后台进行且可以随时取消，图片不太大时
还会自动复制到剪贴板，完成后可以一键打开输出目录。

**聊天提示。** 可选的启动检查会在聊天里提示新版本。累计游玩几个小时后，模组还会在聊天里发一条问卷
邀请，之后最多每天提醒一次，点一下就能永久关闭。

## 按键绑定

所有按键都可以在 Minecraft 原版控制设置里的 "Conflux Map" 分类下修改。装了 MaliLib 后，这些按键会
迁移到它的热键界面（支持多键组合），并且在 1.21.1 及更新版本上，Conflux Map 会出现在 MaliLib 的
A+C 配置切换界面。在 1.17.1、1.18.2 和 1.20.1 上，如果装的 MaliLib 提供同样的注册接口也会自动接入，
否则会保留一个原版快捷键用来打开热键界面。

| 默认按键 | 功能 |
|---|---|
| `H` | 开关小地图 |
| `]` / `[` | 小地图放大 / 缩小 |
| `M` | 打开全屏地图 |
| `Y` | 切换手动图层模式 |
| `U` | 打开路径点列表 |
| `B` | 在当前位置新建路径点 |
| `J` | 显示或隐藏本地路径点 |
| `,` | 打开设置 |
| `P` | 切换地图补全范围（全部 / 仅已生成 / 仅已探索） |
| `F9` | 刷新地图补全瓦片 |

## 多人游戏中的路径点

路径点默认只在创建它的维度显示。有一个可选设置能让主世界和下界的路径点互相可见；末地路径点始终只在
末地显示。

共享路径点需要服务端安装 companion，默认关闭。权限等级 2 的管理员可以用
`/confluxmap waypoints enable` 打开（`disable` 和 `status` 同理）。开启后，任何玩家都能发布一个所有人
可见的路径点，它们会出现在路径点界面的"共享路径点"一栏；只要没被设为标记，发布者可以删除自己发布的
点；设为标记、取消标记以及删除任意点都只能由管理员操作，被标记的点会移到单独的"服务器标记"一栏。
每个世界和每位玩家能发布多少个点，都可以在 `config/confluxmap/server.json` 里调整。

聊天坐标分享不需要 companion，在任何服务器上都能用：发送前会预览即将发出的消息（Conflux Map 和
Xaero 两种格式），收到其他玩家分享的坐标后可以一键导入。

## 服务端 companion

装上 companion 后，全服可以共用同一份实时地图和同一份路径点列表，而不是每个玩家各自维护自己的记录。
Fabric 服务端把对应版本的模组 JAR 放进 `mods/`；Paper 服务端把 `confluxmap-paper-<version>.jar` 放进
`plugins/`（支持 1.21.1 到 26.2，不支持 Folia、Spigot、CraftBukkit）。客户端和服务端版本不需要完全
一致：版本不匹配时会退回体积更大、效率更低的同步方式，版本太旧则只是跳过地形校正同步，而不会
直接失效。

companion 共享的所有内容都在 `config/confluxmap/server.json` 中控制：

- `enabled` 是总开关，关掉后 companion 不再响应任何客户端，所有人都退回到单机行为；
  `checkForUpdates` 会在服务端启动时于控制台提示有新版本。
- `shareSeed` 会把世界种子发给客户端，让它能预测生物群系和结构；`allowBiomeMap` 和
  `allowStructureSearch` 分别控制这两项预测功能是否启用。
- `shareChunkLoadState` 会暴露服务端当前保持加载的区块（默认关闭，因为这会暴露玩家活动和农场位置）。
- `allowEntityRadar` 控制客户端能否扫描和显示实体雷达。
- `shareCorrections` 会把真实地形数据发给客户端，用来覆盖预测结果。
- `shareWaypoints` 开启共享路径点列表。
- `webMap.*` 对应[功能特性](#功能特性)里说的网页地图，默认端口 `8123`，默认只监听 `127.0.0.1`，
  除非显式开放；`sharePlayers` 决定是否包含玩家位置。如果要对外开放，需要放在保留原始 `Host`
  请求头的 HTTPS 反向代理之后。

这些都是隐私和流量方面的选择，不是反作弊手段：修改过的客户端本来就可以自行预测地形或扫描实体，跟
服务端怎么配置无关。

每位玩家的流量限制和带宽预算也在同一个配置文件里；游戏内执行 `/confluxmap performance` 可以看到自己
连接的同步统计。Paper 特有的安装方式、地形访问和数据存储说明见
[`docs/paper-companion.md`](docs/paper-companion.md)。

## 构建

需要 JDK 21 或更高版本（Minecraft、映射表、Fabric API，以及 26.x 构建所需的 JDK 25 工具链，都会由
Gradle 按需自动下载）。

```sh
./gradlew :1.21.11:build
./gradlew :paper:build
./gradlew :paper:runServer
```

可以把 `1.21.11` 换成上面表格里任意一个版本；构建产物会输出到
`versions/<minecraft-version>/build/libs/`，独立的 Paper 插件输出到 `paper/build/libs/`。
`:paper:runServer` 会下载一个本地 Paper 1.21.1 开发服务器并装上刚构建的插件；首次运行需要在
`paper/run/eula.txt` 中同意 Minecraft EULA，然后再次执行该任务。
