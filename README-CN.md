# Conflux Map

[English](README.md) | **简体中文**

Conflux Map 是一款面向多人游戏的 Fabric 小地图与世界地图模组。它将小地图、世界地图、群系地图、区块加载票地图、结构查找器和路径点同步等功能整合于一个客户端 JAR 中，并将单次全服地图同步的数据量控制在数百字节至数百 KB 的范围内。

## 安装

请在 [Releases](../../releases) 页面下载对应 Minecraft 版本的 JAR（也可参考下方[构建](#构建)自行编译），并将其放入 `mods/` 目录，同时安装 [Fabric API](https://modrinth.com/mod/fabric-api)。[MaliLib](https://modrinth.com/mod/malilib) 为可选组件；安装后可使用组合键绑定，Conflux Map 也会显示在 MaliLib 的 A+C 设置切换界面中。

客户端安装完成后，即可使用本地地图、路径点、绘图和地图导出等功能。安装服务端 companion 后，服务器还可提供全服地图同步、公共路径点、地图校正、区块加载票地图和网页地图等服务端能力。详细说明请参阅[服务端 companion](#服务端-companion)。

## 功能特性

### 核心能力

- **全图地图同步：** 通过预测地图、权威地图、瓦片分块和增量更新，实现低带宽的全服地图同步；单次同步流量控制在数百字节至数百 KB 的范围内。
- **公共路径点：** 服务端可维护全服共享路径点，集中记录农场、建筑和重要地点，所有 Conflux Map 客户端均可查看。
- **网页地图：** 服务端 companion 可提供独立的浏览器地图，显示已探索地形、预测地形和共享路径点；管理员还可配置玩家位置、名称、维度和界面语言等显示内容。

### 地图补全与世界探索

- **地图补全：** 获取世界种子后，主世界、下界基岩顶层和末地区域可立即显示预测地形；随着玩家探索或服务端返回校正数据，预测结果会逐步替换为真实地图。按 `P` 可在全部预测、仅已生成区域和仅已探索区域之间切换，也可在本地配置种子以生成专属预测地图。
- **地图图层：** 全屏地图支持“地图”“群系”和“加载等级”三种模式；“加载等级”模式提供“状态分级”和“精确等级”两种显示精度。主世界支持地表、当前洞穴和配置的固定高度，下界支持当前层、基岩顶层和配置的基岩下方高度；小地图和全屏地图都会显示当前高度或固定 Y 值。末地使用适配虚空环境的背景。地图光照会同时跟随原版 gamma 选项、昼夜和附近方块光照。
- **结构查找器：** 主世界、下界和末地中的原版结构均配有独立图标、分类显示开关及总开关。村庄群系、堡垒遗迹布局、僵尸村庄、带末地船的末地城等受支持的变种会使用不同名称和图标。用户可以按名称搜索最近结构，也可以指定中心坐标、半径和结果数量，列出指定范围内的全部候选位置，并将任意候选位置直接保存为路径点。右键单击结构图标时，位置菜单会使用该结构的精确生成点。
- **子世界管理：** 面对同一地址背后的多个服务器（例如代理网络）时，地图数据会按世界分别保存。用户可以在子世界界面中新建、重命名和清除识别记录，合并种子相同的旧地图缓存，并迁移旧记录中的路径点。
- **服务器地址关联：** 同一台服务器具有多个地址时，可通过服务器地址管理共用地图缓存、路径点和本地种子；安装 companion 后，服务端还可直接告知客户端多个地址是否指向同一世界。

### 小地图与世界地图

- **小地图 HUD：** 支持方形或圆形外观、自由缩放、跟随视角旋转和位置调整；坐标、当前生物群系和正在使用的图层等信息均可按需显示，并能在与原版 HUD 元素发生遮挡时自动调整显示位置。
- **全屏世界地图：** 支持连续缩放、区块网格、平滑拖动和以光标为中心缩放；右键点击即可创建路径点、分享坐标或执行传送。

### 路径点与地图标记

- **本地路径点与死亡点：** 路径点支持名称、颜色和分组管理；列表支持搜索、分组筛选以及批量选择和移动。每个维度会自动保留死亡点，默认保留 5 个，数量可在 0–50 个之间调整。
- **世界内标记：** 路径点可显示光柱、名称和距离；视野外的路径点通过屏幕边缘指示器提示方向，并可设置显示距离上限。主世界与下界可按 1:8 的传送门坐标比例互相显示路径点。
- **聊天分享与跨 Mod 导入：** 聊天坐标支持 Conflux Map 和 Xaero 两种格式的预览与一键导入；路径点可从 Xaero's Minimap 和 VoxelMap 一键导入，重复项将自动跳过，原文件保持不变。

### 地图绘图与导出

- **地图绘图工具：** 支持直线、图形、自由笔迹和文字标签；已完成的内容支持选中、移动、改色、删除、橡皮擦、撤销和重做，并可永久保存或同步显示在小地图上。
- **近期足迹：** 小地图和全屏地图均可显示最近一段时间的移动足迹，足迹时长、圆点大小和显示状态均可调整。
- **自定义范围 PNG 导出：** 地图上的任意区域均可导出为指定分辨率的 PNG；用户可以输入矩形区域两个角的坐标或直接在地图上框选范围，并选择是否包含绘图内容。导出任务支持文件大小预估、后台运行、进度查看、取消、剪贴板复制和输出目录打开。

### 实体雷达与界面设置

- **实体雷达：** 玩家、敌对生物、友善生物和其他实体均设有独立开关，并默认全部显示。小地图默认显示依据生物模型或物品外观生成的实体头像，也可改为按类别着色的小点；小点模式下按住玩家列表键可临时展开详细图标。全屏地图始终显示详细图标。
- **显示内容自定义：** 小地图、路径点、实体雷达、图层和信息栏均提供细致的显示内容配置，客户端设置支持即时生效，滑块支持直接输入数值。
- **UI 资源包：** 工具栏图标和小地图边框可通过 Minecraft 普通资源包替换；从 Xaero 迁移时，已有资源包中的兼容小地图边框和世界地图图标可以继续使用。支持的路径和限制见 [UI 资源包说明](docs/reference-specs/ui-resource-packs.md)。
- **MaliLib 组合快捷键：** 安装 MaliLib 后支持多键组合，并可通过 A+C 配置界面管理 Conflux Map。
- **更新提示：** 可选的启动检查会在聊天中提示新版本；累计游玩数小时后，模组还会发送问卷邀请，用户可通过提示操作管理后续通知。

## 按键绑定

所有按键均可在 Minecraft 原版控制设置中的“Conflux Map”分类下修改。安装 MaliLib 后，按键会迁移至其热键界面，并支持多键组合；在 1.21.1 及更高版本中，Conflux Map 还会出现在 MaliLib 的 A+C 配置切换界面。在 1.17.1、1.18.2 和 1.20.1 中，如果所安装的 MaliLib 提供相应注册接口，模组也会自动接入；否则将保留一个用于打开热键界面的原版快捷键。

| 默认按键 | 功能 |
|---|---|
| `H` | 开关小地图 |
| `]` / `[` | 小地图放大 / 缩小 |
| `M` | 打开全屏地图 |
| `Y` | 循环切换自动、地表/顶层、当前高度和配置的固定高度图层 |
| `U` | 打开路径点列表 |
| `B` | 在当前位置新建路径点 |
| `J` | 显示或隐藏本地路径点 |
| `,` | 打开设置 |
| `P` | 切换地图补全范围（全部 / 仅已生成 / 仅已探索） |
| `F9` | 刷新地图补全瓦片 |

## 路径点使用

主世界和下界的路径点默认会按 8:1 坐标换算后跨维度显示，也可在设置中关闭；末地路径点始终仅显示在末地。

共享路径点需要在服务端安装 companion，安装后默认启用。普通玩家可以发布全员可见的路径点并管理自己发布的条目；管理员可管理全部条目，也可使用 `/confluxmap waypoints disable`、`enable` 和 `status` 控制该功能。未安装 Conflux Map 的玩家也可在当前位置使用 `/confluxmap waypoints add <name>` 发布路径点，并使用 `/confluxmap waypoints list [page]` 分页查看同一公共列表。列表条目同时提供 Xaero 聊天分享格式，便于一键导入；管理员可使用列表显示的短 ID 执行 `edit`、`move`、`delete`、`lock` 和 `unlock` 操作。未设为标记的路径点可由发布者删除；设置或取消标记，以及删除任意路径点，仅限管理员执行。标记后的路径点将移动至“服务器标记”一栏。每个世界及每位玩家可发布的路径点数量，均可在 `config/confluxmap/server.json` 中调整。

聊天坐标分享无需 companion，可在任何服务器上使用。发送前会预览即将发出的消息（包括 Conflux Map 和 Xaero 两种格式），收到其他玩家分享的坐标后可一键导入。

## 服务端 companion

安装 companion 后，全服可共用同一份实时地图和路径点列表。Fabric 服务端应将对应版本的模组 JAR 放入 `mods/`；Paper 服务端应将 `confluxmap-paper-<version>.jar` 放入 `plugins/`（支持 Paper 1.21.1 至 26.2）。客户端与服务端版本可独立升级：预测算法一致时使用体积较小的差分同步，预测算法不一致时使用完整数据同步；较旧协议仍可提供基础地图服务。

companion 提供的共享内容均在 `config/confluxmap/server.json` 中控制：

- `enabled` 为总开关；`checkForUpdates` 用于在服务端启动时于控制台提示新版本。
- `shareSeed` 将世界种子发送至客户端，使客户端能够预测生物群系和结构；`allowBiomeMap` 与 `allowStructureSearch` 分别控制群系地图和结构查找功能。
- `shareChunkLoadState` 用于公开服务端当前保持加载的区块，默认关闭，以减少玩家活动和农场位置的暴露。
- `allowEntityRadar` 控制客户端 Conflux Map 小地图中的实体位置显示功能。
- `shareCorrections` 用于向客户端发送真实地形数据，以校正预测结果。
- `shareWaypoints` 用于启用共享路径点列表，默认开启；`allowNonOperatorSharedWaypointManagement` 默认允许普通玩家管理自己发布的条目。
- `webMap.*` 对应功能特性中的网页地图，默认开启。默认端口为 `8123`，仅监听 `127.0.0.1`，且不包含玩家位置；如需对外开放，应将其置于保留原始 `Host` 请求头的 HTTPS 反向代理之后。`sharePlayers` 用于控制是否包含玩家位置。

上述配置项可供服务器根据自身的隐私、流量和反作弊策略控制相关功能。需要注意的是，对客户端而言，实体数据仍会正常发送；`allowEntityRadar` 仅禁用客户端 Conflux Map 小地图中的实体位置显示功能。

每位玩家的流量限制和带宽预算也在同一个配置文件中。玩家可在游戏内执行 `/confluxmap performance` 查看当前连接的同步统计。Paper 特有的安装方式、地形访问和数据存储说明见 [`docs/paper-companion.md`](docs/paper-companion.md)。

## 构建

需要 JDK 21 或更高版本（Minecraft、映射表、Fabric API，以及 26.x 构建所需的 JDK 25 工具链，都会由
Gradle 按需自动下载）。

```sh
./gradlew :1.21.11:build
./gradlew :paper:build
./gradlew :paper:runServer
```

可以把 `1.21.11` 换成上面表格里任意一个版本；构建产物会输出到
`versions/<minecraft-version>/build/libs/`，独立的 Paper 插件输出到 `paper/build/libs/`。
`:paper:runServer` 会下载一个本地 Paper 1.21.1 开发服务器并装上刚构建的插件；首次运行需要在
`paper/run/eula.txt` 中同意 Minecraft EULA，然后再次执行该任务。
