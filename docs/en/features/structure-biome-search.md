# Structure & biome search

The fullscreen map includes a built-in search screen with **Structure** and **Biome** modes to locate targets without leaving the game.

## Structure Search

- **Distinct Icons & Variants**: Vanilla structures in the Overworld, Nether, and End each have a distinct icon and category toggle; variants such as village biomes, bastion layouts, zombie villages, and End Cities with ships use separate names and icons.
- **Search Modes**:
  - Find the nearest structure by name;
  - Specify a center, radius, result count, and variant filter to list candidates within an area.
- **Actions**: Right-clicking a structure icon opens the location menu at its exact generation point; any candidate in the list can be saved directly as a waypoint.

## Biome Search

- Pick a biome by name to scan the explored map;
- Once the world seed is available, the search extends into predicted terrain from [Autofill & prediction](autofill-prediction.md) beyond explored chunks.

!!! tip "Sorting"
    Candidate lists are ordered **nearest-first** by default and can be switched to **farthest-first** to prioritize distant matches.
