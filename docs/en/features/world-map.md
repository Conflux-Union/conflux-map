# World map

- Continuous zoom, smooth panning, and a chunk grid, with zooming centered on
  the cursor.
- Three layers: map, biome, and load level. Load level offers two display
  precisions, status bands and exact levels. The Overworld provides surface,
  current-cave, and fixed-height layers; the Nether provides current-level,
  bedrock-roof, and below-bedrock layers; the End uses a void-adapted
  background. The height currently displayed is labeled on the map.
- Map lighting follows the vanilla brightness setting, the in-game time of
  day, and nearby block light.
- Right-click the map to create a waypoint or share coordinates; a teleport,
  including cross-dimension targets, is offered where the server permits it.
