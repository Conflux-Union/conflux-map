# Portal markers

Activated nether portals, end portals, and end gateways you have seen are
marked on the minimap and the world map. Each portal gets an icon at its
position and, optionally, a translucent highlight over the chunk containing
it; each portal kind's icon can be set to any texture resource location, and
icon size, opacity, and highlight color are configurable in settings. Markers
are remembered per world and per dimension, and a portal dismantled
elsewhere disappears once you load its chunk again. Detection is purely
client-side, so portals are known only from chunks you have loaded.

See also: [World map](world-map.md), [Waypoints](waypoints.md)
