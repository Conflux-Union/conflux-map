# Display and appearance

- The mod's own screens and popups can fade and scale in when opened. The
  animation can be disabled, or set to one of three speeds, under
  Settings → General → Interface.
- The minimap, waypoints, entity radar, layers, and info lines each provide
  independent display settings, and every change takes effect immediately.
- Toolbar icons and minimap frames can be replaced through normal Minecraft
  resource packs; compatible assets from existing Xaero UI packs continue to
  work. Supported paths and limits are documented in
  [UI resource packs](https://github.com/Conflux-Union/conflux-map/blob/master/docs/reference-specs/ui-resource-packs.md).
- An optional update check announces new versions in chat. After several
  hours of play, a one-time survey invitation may appear, and the prompt
  lets you disable further notices.

See also: [Minimap](minimap.md), [Waypoints](waypoints.md)
