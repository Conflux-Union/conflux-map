# Multi-server data management

- A single address can lead to several worlds, for example behind a proxy
  network. Map data is stored per world; the sub-world screen can create,
  rename, and clear identification records, merge an older same-seed map
  cache into the current world, and move waypoints from an older record.
- When one server is reachable through several addresses, those addresses
  can be linked to share the map cache, waypoints, and local seed. A server
  with the companion installed also informs the client directly which
  addresses point to the same world.
