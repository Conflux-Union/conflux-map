# Conflux Map

A client-side minimap and world-map mod for Fabric, with optional server
companions for a live web map and shared waypoints.

- [Minimap](features/minimap.md) — square or round, free placement, HUD
  avoidance
- [World map](features/world-map.md) — three layers, zoom-to-cursor,
  height layers per dimension
- [Autofill & prediction](features/autofill-prediction.md) — predicted
  terrain from the world seed, replaced as you explore
- [Structure & biome search](features/structure-biome-search.md) ·
  [Chest loot preview](features/chest-loot-preview.md) ·
  [Portal markers](features/portal-markers.md)
- [Waypoints](features/waypoints.md) ·
  [Shared waypoints](features/shared-waypoints.md) ·
  [Entity radar](features/entity-radar.md)
- [Drawings & export](features/drawings-export.md) ·
  [Appearance](features/appearance.md) ·
  [Multi-server data](features/multi-server.md)
