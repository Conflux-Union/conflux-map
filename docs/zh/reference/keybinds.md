# 按键绑定

所有默认按键均可在原版「**选项 → 控制 → 按键绑定 → Conflux Map**」分类下自由修改。

!!! info "MaliLib 热键支持"
    安装可选依赖 [MaliLib](https://modrinth.com/mod/malilib) 后，所有按键绑定会自动迁移至 MaliLib 的热键界面，支持**多键组合**；在 Minecraft `1.21.1` 及以上版本中，Conflux Map 还会出现在 MaliLib 的 `A+C` 设置切换界面中。

## 默认按键一览

| 默认按键 | 所属功能 | 动作说明 |
|---|---|---|
| `H` | 小地图 | 开启或关闭 HUD 小地图 |
| `]` | 小地图 | 循环切换小地图缩放级别 |
| `M` | 世界地图 | 打开全屏世界地图 |
| `Y` | 图层切换 | 循环切换自动、地表/顶层、当前高度与配置的固定高度图层 |
| `U` | 路径点 | 打开路径点列表界面 |
| `B` | 路径点 | 在当前玩家位置新建路径点 |
| `J` | 路径点 | 显示或隐藏本地路径点 |
| `,` | 通用设置 | 打开 Conflux Map 设置界面 |
| `P` | 地图补全 | 循环切换补全范围（全部预测 / 仅已生成 / 仅已探索） |
| `F9` | 地图补全 | 强制刷新地图补全瓦片 |
| （未绑定） | 路径点 | 在当前位置放置临时路径点（退出世界后消失） |
