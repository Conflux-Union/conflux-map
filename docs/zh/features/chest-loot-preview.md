# 箱子战利品预览

获取世界种子后,全屏地图上结构标记的位置菜单会出现「战利品」入口,
结构搜索界面的地图窗格也承载同一菜单。选择「战利品」可预览结构内的每个箱子:
方块坐标、战利品表,以及预测的物品列表——每组的物品、数量、附魔及等级,
存在效果时一并显示。预览的是箱子在世界生成时那次确定性的原版战利品结果,
由世界种子在客户端本地计算:不受玩家上下文影响,未探索区块同样可用。

战利品预览覆盖预测功能可枚举箱子的结构——沙漠神殿、丛林神庙、雪屋、沉船、
掠夺者前哨站、废弃传送门(下界变种自 1.18.2 起)、埋藏的宝藏、下界要塞、
堡垒遗迹、末地城、要塞,以及 26.3 的废弃营地;村庄、海底废墟、林地府邸、
远古城市、废弃矿井、试炼密室、怪物房间等结构不会显示「战利品」入口。
仅支持原版战利品表:被数据包修改的战利品表不在预览范围内,无法模拟的箱子
仍会显示其方块坐标与战利品表。
