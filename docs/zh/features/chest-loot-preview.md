# 箱子战利品预览

获取世界种子后，在全屏地图上右键结构标记打开位置菜单（或在结构搜索界面的地图窗格中），即可看到**「战利品」**入口，用于预览该结构内每个箱子的物品。

## 预览内容与原理

选择「战利品」后，界面会按原版容器样式展示结构内的每个箱子，包括：

- 箱子的精确**方块坐标**与对应的**战利品表**；
- 预测的**物品列表**：每组物品的种类、数量、附魔及等级，以及药水/迷之炖菜等状态效果（存在时一并显示）。

!!! info "计算机制"
    预览结果是根据世界种子在**客户端本地**计算的初始原版战利品（即箱子在世界生成时的内容），不受玩家幸运值或上下文影响，即使区块尚未探索也可预览。

## 支持的结构范围

战利品预览覆盖了可按世界种子固定枚举箱子位置的原版结构：

| 支持预览的结构 | 暂不支持的结构 |
|---|---|
| 沙漠神殿、丛林神庙、雪屋、沉船 | 村庄、海底废墟、林地府邸 |
| 掠夺者前哨站、废弃传送门（下界变种自 1.18.2 起）、埋藏的宝藏 | 远古城市、废弃矿井、试炼密室、怪物房间 |
| 下界要塞、堡垒遗迹、末地城、要塞、废弃营地（26.3） | — |

!!! warning "数据包限制"
    本功能仅支持原版战利品表。被服务器或整合包通过数据包修改过的战利品表不做预测，无法模拟的箱子仍会显示其方块坐标与战利品表名称。
