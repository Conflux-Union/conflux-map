# 绘图与导出

- 支持在地图上绘制直线、图形、自由笔迹与文字标签;绘制完成后可选中、移动、
  改色与删除,并支持撤销与重做。绘图内容随世界保存,亦可显示在小地图上。
- 测距工具用左键在地图上标点,实时显示每段距离与总长度;右键或 Ctrl+Z
  撤销上一点,测点按维度保留,撤销完即自动退出。
- 在全屏地图上按住右键拖动即可框选范围,选框自动对齐区块边界,中心实时标注
  区块数与方块数;选区高亮保留到下一次任意操作。
- 任意区域均可导出为指定分辨率的 PNG:可输入矩形两角的坐标,或直接在地图上
  框选范围。导出任务在后台运行,提供大小预估、进度显示与取消操作,
  完成后可复制到剪贴板或直接打开输出目录。
- Xaero 世界地图记录的地形数据可以导入本地图:在地图屏幕的操作工具中选择
  导入入口。Conflux Map 会读取该安装自身数据文件中已探索的地形,按维度逐一
  合并进本地地图缓存(只填充尚无本模组捕获的位置),因此即使没有服务端组件,
  此前探索过的地形也能直接显示。重复导入不会覆盖 Conflux Map 自己捕获的地形;
  实机重访已导入区域时,实时捕获会自动替换导入数据。
