# 绘图与导出

全屏世界地图内置了手绘标注、多段测距、区域框选 PNG 导出以及 Xaero 地形导入等实用工具。

## 地图绘图

- 支持在地图上绘制**直线、图形、自由笔迹与文字标签**；
- 绘制完成后支持选中、移动、改色、删除，以及撤销与重做；
- 绘图内容随世界保存，也可同步显示在小地图上。

## 测距工具

- 使用左键在地图上连续标点，实时显示每一段的距离与总长度；
- 右键或按 `Ctrl+Z` 撤销上一个测点；测点按维度保留，全部撤销后自动退出测距模式。

## 框选与高清 PNG 导出

- **快捷框选**：在全屏地图上按住**右键拖动**即可框选范围，选框自动对齐区块边界，中心实时标注区块数与方块数；选区高亮保留到下一次任意操作。
- **后台导出 PNG**：输入矩形两角坐标或直接使用当前框选范围，即可导出指定分辨率的 PNG 图片。导出任务在后台运行，支持文件大小预估、进度显示与取消操作，完成后可直接**复制到剪贴板**或**打开输出目录**。

## Xaero 地图数据一键迁移

在全屏地图的操作工具中选择导入入口，可将 **Xaero's World Map** 记录的地图数据合并进 Conflux Map：

- 按维度读取 Xaero 数据文件并合并进本地缓存，**仅填充尚无本模组捕获的位置**；
- 即使服务器未安装服务端组件，此前探索过的地图区域也能直接显示；
- 重复导入不会覆盖 Conflux Map 自己捕获的地图数据；实机重访已导入区域时，实时捕获会自动替换导入数据。
