# 实体雷达

实体雷达用于在地图上实时显示周围的玩家、生物与掉落物等实体位置。

## 分类与精细控制

- **类别开关**：玩家、敌对生物、友善生物与其他实体各有独立开关，默认全部显示。
- **单个实体覆盖**：在雷达设置的「**管理实体显示**」中，可按具体实体类型强制显示或隐藏，不受其所属大类开关的影响。

## 图标显示模式

- **小地图**：默认显示按生物生成的头像与按物品生成的图标；也可切换为按类别着色的小点，按住原版「玩家列表」键时临时展开为详细图标。
- **全屏世界地图**：始终显示详细图标。

!!! note "服务端玩家位置同步"
    当服务器安装了[服务端组件](../technical/server-companion.md)并开启 `allowEntityRadar` 时，客户端会额外接收全服在线玩家的实时位置，从而支持超视距与跨维度查看及右键高亮追踪。这部分全图玩家显示由服务端位置流提供，独立于本地实体雷达的生物过滤。
