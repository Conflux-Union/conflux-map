# 显示与外观

## 界面动画与实时设置

- **打开动画**：模组自身的界面与弹窗打开时支持淡入并轻微缩放，可在「**设置 → 通用 → 界面**」中关闭，或在三档速度中选择。
- **即时生效**：小地图、路径点、实体雷达、图层与信息栏均拥有独立的显示设置，修改后立即生效。

## 资源包与主题兼容

- 工具栏图标与小地图边框均可通过普通 Minecraft 资源包替换。
- 兼容 **Xaero UI 资源包**中的可用素材，具体支持的纹理路径与限制参见 [UI 资源包说明](https://github.com/Conflux-Union/conflux-map/blob/master/docs/reference-specs/ui-resource-packs.md)。

## 更新提示与问卷

- 可选的更新检查会在进入游戏时于聊天栏提示新版本。
- 累计游玩数小时后可能会出现一次问卷邀请，可在提示界面中关闭后续通知。
