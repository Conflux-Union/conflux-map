# 多服务器数据管理

针对 Velocity 等代理网络或多域名入口服务器，Conflux Map 提供了完善的世界数据隔离与合并管理机制。

## Velocity 与子世界管理

- **按世界隔离**：同一服务器地址下可能对应多个子世界，地图数据会按世界分别保存。
- **合并与迁移**：在子世界界面中支持新建、重命名与清除识别记录，可将旧的同种子地图缓存合并至当前世界，并一并迁移旧记录中的路径点。

## 多地址关联

- **手动关联**：当同一服务器拥有多个连接地址时，可将地址关联，共用同一份地图缓存、路径点与本地种子。
- **服务端自动识别**：若服务器安装了[服务端组件](../technical/server-companion.md)，服务端会直接告知客户端哪些地址指向同一世界，无需手动配置。
