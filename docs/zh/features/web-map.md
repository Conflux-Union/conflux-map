# 网页地图

服务端组件内置了浏览器网页地图，默认监听 `127.0.0.1:8123`——绑定地址、公网暴露与隐私设置见[服务端组件](../technical/server-companion.md)。任何拿到地址的人都可以在普通浏览器中查看已探索地形、预测地形、公共路径点与在线玩家，无需安装任何模组。

## 浏览

- **维度与模式**：切换维度，并选择网页提供的区域范围——全部区域或仅已生成区域（管理员可为新访客设定默认模式）。
- **中心坐标**：左下角显示当前视口中心 `X`/`Z`。
- **玩家与路径点搜索**：将视图跳转到在线玩家或公共路径点；服务器可分别关闭两种搜索。
- **网页聊天**：可选的聊天面板，在浏览器与游戏之间转发消息。默认关闭，游戏聊天的转发与网页发言均由服务器控制。
- **语言**：界面跟随浏览器语言，也可手动切换。

## 多服共用一个入口

同一台主机上的 Fabric 与 Paper 服务端可以共用一个网页地图入口。网页提供「**切换服务端**」下拉框列出所有实例，服名后的游戏模式后缀也可关闭显示。

## 玩家与照片

- **玩家头像**：地图标记与玩家列表显示玩家皮肤的脸部；皮肤不可用时显示默认头像。
- **公共路径点照片**：审核通过的照片会随公共路径点在网页中显示——发布与审核流程见[共享路径点](shared-waypoints.md)。
- **玩家隐私**：每位玩家可在游戏内用 `/confluxmap webmap hide` / `show` 控制自己在网页地图上的可见性。
