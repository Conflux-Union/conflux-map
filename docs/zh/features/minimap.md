# 小地图

HUD 小地图在游戏画面中实时显示玩家周围的地形与实体状态，全部渲染均在客户端完成。

## 核心能力

- **外观与布局**：支持**方形**与**圆形**两种边框外观，位置、大小和旋转角度均可自由调整。
- **信息显示**：可按需开启或关闭坐标、当前群系名称以及当前活动图层的显示。
- **HUD 智能避让**：自动避让原版 HUD 元素（如右上角状态效果图标等），避免信息重叠。

## 常用操作

- 按 `H` 开启或关闭小地图。
- 按 `]` 循环切换小地图的缩放比例。
