# 路径点

- 支持名称、颜色与分组;列表支持搜索、筛选与批量移动。
- 每个维度自动记录死亡点,默认保留 5 个,可在 0 至 50 之间调整。
- 路径点在世界内显示为光柱、名称与距离;视野外的路径点通过屏幕边缘指示器
  提示方向,显示距离上限可调。
- 主世界与下界的路径点默认按 1:8 的传送门坐标换算跨维度显示,可在设置中关闭;
  末地路径点仅显示在末地。
- 同一服务器下种子相同的多个子世界可以互相显示路径点。该功能默认关闭,
  可在设置中开启"显示同种子世界路径点"。
- 在聊天中分享坐标前可预览 Conflux Map 与 Xaero 两种格式,其他玩家分享的
  坐标可一键导入。
- 路径点支持从 Xaero's Minimap 与 VoxelMap 一键导入,重复项自动跳过,
  原文件保持不变。

## 路径点增强(26.3)

26.3 增强功能:在路径点图标左侧点击星标即可收藏并置顶,再次点击取消。编辑窗口中的“备注标签”支持预设标签、自定义备注和可搜索的资源产物(包括模组物品)。列表搜索会匹配这些内容。

路径点界面新增“设置”入口,打开 CM 原生设置的“路径点”分类。普通列表默认保持原有布局;在“路径点增强”中打开“紧凑路径点列表”后,仅列表区域改为网格,顶部筛选和底栏按钮位置保持一致。紧凑列表支持本地与公共合并显示;排序依次为收藏、来源优先级、距离。悬浮路径点可以编辑、隐藏、确认删除、分享、定位、传送或浏览图片。快速发布会创建公共副本并保留本地原点,仍受服务器权限及重复发布检查约束。原生设置为收藏、搜索/备注/标签增强、图片管理、列表/地图图片预览、紧凑列表、合并显示、悬浮操作、来源排序、快速发布、列表记忆、临时点快捷键和未知高度回退提供开关;关闭后保留已有数据。关闭自动悬浮操作时可右键打开操作面板。原有设置仍可调整默认来源和维度范围;不会恢复勾选和删除确认。

保存路径点后,在“备注标签 → 图片”导入或直接拖入 PNG/JPEG。支持多张图片、说明、前后排序、移除和缩放;图片操作立即保存,不随备注草稿取消。每点最多 64 张,单张最多 32 MiB / 4000 万像素。图片复制到本机 `confluxmap/waypoint-media`,公共路径点的图片也不会上传;移除仅解除关联并保留本机副本,导入的外部原文件保持不变。紧凑悬浮面板和全屏地图悬浮入口可预览首张缩略图。临时路径点快捷键默认未绑定,可在按键设置里配置,离开世界后消失。使用 MaliLib 时会补入旧版临时路径点绑定,已有 CM 绑定(包括主动清空)保持不变。

首次启用会读取 `config/halfmasa` 的旧 CM 配置和浏览记忆,保留旧文件,之后以 CM 自身设置为准。使用前请关闭 halfmasa 的 CM 扩展总开关,避免两套功能同时处理操作。
