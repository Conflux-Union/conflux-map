# 结构与群系搜索

主世界、下界与末地的原版结构均有独立图标和分类开关;村庄群系、堡垒遗迹布局、
僵尸村庄、带船末地城等变种使用单独的名称与图标。全屏地图的搜索界面提供
「结构」与「群系」两种模式。可按名称搜索最近的结构,也可指定中心、半径、
数量与变种筛选,列出指定区域内的候选位置并直接保存为路径点;群系同样按名称
选择并定位,先扫描已探索地图,获取世界种子后还会延伸到未探索区域的预测结果。
候选列表默认由近到远排序,也可切换为由远到近以优先显示最远的匹配。
右键结构图标,位置菜单会在该结构的精确生成点打开。
