# 结构与群系搜索

全屏世界地图内置搜索界面，提供**结构**与**群系**两种定位模式，无需切出游戏即可查找目标位置。

## 结构搜索

- **独立图标与细分变种**：主世界、下界与末地的原版结构均配有独立图标与分类开关；**村庄群系、堡垒遗迹布局、僵尸村庄、带船末地城**等变种会使用单独的名称与图标区分。
- **两种查找方式**：
  - 按名称直接搜索最近的结构；
  - 指定搜索中心、半径、结果数量与变种筛选条件，列出区域内的所有候选位置。
- **交互操作**：右键地图上的结构图标，位置菜单会在该结构的精确生成点打开；候选列表中的任意结果均可直接保存为路径点。

## 群系搜索

- 按名称选择目标群系后，系统会先扫描已探索的真实地图；
- 当客户端获取到世界种子时，搜索范围会自动延伸至未探索区域的[地图补全](autofill-prediction.md)预测结果。

!!! tip "排序方式"
    候选列表默认按**由近到远**排序，也可一键切换为**由远到近**以优先查看最远的匹配目标。
