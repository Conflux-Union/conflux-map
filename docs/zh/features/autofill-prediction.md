# 地图补全

地图补全功能可根据世界种子在客户端本地预测未探索区域的地形，让玩家无需盲目跑图即可预览周边地貌。

## 工作方式

- **覆盖维度**：获取世界种子后，**主世界、下界基岩顶层与末地**会立即显示预测地形。
- **真实地形替换与校正**：随着探索推进，预测结果会逐步被实机渲染的真实地图替换；若服务器安装了[服务端组件](../technical/server-companion.md)并开启校正，服务端还会主动下发真实地形数据修正预测结果。
- **本地种子支持**：当服务器未下发种子时，客户端可在设置中配置「本地种子」，生成仅对自己可见的预测地图。

## 性能与控制

- **计算后端**：预测默认使用 **AUTO** 后端：每台机器首次启动会实测 GPU 与 CPU 池谁更快并选用快者（核显等较慢的 GPU 会自动落在 CPU）；可在「地图补全设置」中手动切换后端。
- **快捷操作**：
  - 按 `P` 在「**全部预测 / 仅已生成 / 仅已探索**」之间循环切换；
  - 按 `F9` 强制刷新地图补全瓦片。

!!! note "服务端权限说明"
    在多人服务器中，服务端可通过 `config/confluxmap/server.json` 中的 `shareSeed` 控制是否下发种子，或通过 `allowPrediction` 禁用配合客户端的预测图层。
