# 世界地图

按 `M` 打开全屏世界地图，用于全局浏览已探索地形、预测地形与各类标记。

## 浏览与交互

- **连续缩放与平移**：支持以鼠标光标为中心的无极缩放、平滑拖动与区块网格叠加；最小缩放极限可调整为默认极限（0.015625×）的 80%–200%，最大缩放极限可调整为默认极限（8×）的 20%–200%（悬停滑条可查看原极限）。
- **坐标跳转**：输入 `X`/`Z` 坐标（±30,000,000 以内）即可跳转，背景地图保持可见。
- **动态光照**：地图光照跟随原版亮度设置、游戏内昼夜变化以及附近的方块光照。
- **右键位置菜单**：右键地图任意位置可创建路径点或分享坐标；在服务器权限允许时亦可直接传送，默认支持跨维度目标。

## 图层与高度视图

世界地图提供**地图、群系、加载等级**三种图层，按 `Y` 可在常用高度视图之间循环切换：

| 维度 / 图层 | 说明 |
|---|---|
| **主世界** | 分为**地表**、**当前洞穴**与**固定高度**三类视图 |
| **下界** | 分为**当前层**、**基岩顶层**与**基岩下方**三类视图 |
| **末地** | 使用适配虚空环境的专用背景 |
| **加载等级图层** | 提供「状态分级」与「精确等级」两种显示精度——多人联机由服务端组件提供，单人游戏由内置服务器提供；当前显示高度会直接标注在地图上 |

## 标记开关与视图

- **路径点与结构**：可独立开关**结构图标**、**地狱门**、**折跃门**与**地图截图**；开启「对应路径点显示图片」后，路径点图片也会出现在地图上（见[路径点](waypoints.md)）。
- **视图**：开关真实地图范围高亮、区块网格与加载等级图层；在地图上按住右键框选可临时显示区块网格。

!!! tip "真实地图范围高亮"
    覆盖范围高亮只标记客户端真正看过的地形——种子预测地形不计入覆盖范围。显示方式可选「预测及空白区域变暗」或「白色内实外虚」，也可再用「预测及空白区域亮度」（0–100%）进一步压暗未探索部分；真实地形始终保持原亮度。
