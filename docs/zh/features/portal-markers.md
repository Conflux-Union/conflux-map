# 传送门标记

Conflux Map 可在小地图与全屏世界地图上标记玩家见过的**已激活下界传送门、末地传送门与末地折跃门**。

## 功能细节

- **图标与区块高亮**：每个传送门会在所在坐标显示专属图标，并可选地为其所在区块叠加半透明高亮。
- **高度可定制**：可在设置中为每种传送门分别指定任意纹理资源路径，并调整图标大小、不透明度与区块高亮颜色。
- **自动更新与清理**：标记按世界与维度分别记忆。若别处有传送门被拆除，当玩家再次加载其所在区块时，旧标记会自动消失。

!!! note "检测范围"
    传送门检测完全在客户端完成，因此只有你实际加载过的区块中的传送门会被记录。
