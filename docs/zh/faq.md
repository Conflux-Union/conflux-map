# 常见问题与兼容性

## 安装与基础问题

??? question "模组需要服务端安装什么吗？"
    **不需要。** 小地图、世界地图、路径点、绘图与导出全部在客户端本地完成。

    如果服务器额外安装了[服务端组件](technical/server-companion.md)，则会获得实时网页地图、共享路径点、真实地形校正与区块加载等级图。

??? question "支持哪些 Minecraft 版本？"
    每个版本线提供一个构建，覆盖 **1.17.1 至 26.3**——完整列表参见[支持的版本表](getting-started/install.md#支持的版本)。Paper 服务端自 `1.21.1` 起通过独立插件支持。

??? question "必须安装 MaliLib 吗？"
    **可选。** 安装 [MaliLib](https://modrinth.com/mod/malilib) 后按键支持多键组合，且 Conflux Map 会出现在 MaliLib 的 `A+C` 设置切换界面中；不安装则直接使用原版控制设置。

## 地图补全与战利品预览

??? question "为什么进入服务器后没有自动显示预测地形？"
    地图补全依赖世界种子：

    - 单人世界通常会自动获取种子；
    - 多人服务器中，服务端默认关闭 `shareSeed`（避免暴露种子），此时可在客户端设置中手动配置**本地种子**；
    - 如果已配置种子仍未显示，请按 `P` 确认补全模式未切换到「仅已探索」，或按 `F9` 强制刷新。

??? question "为什么有些结构有箱子战利品预览，有些没有？"
    预览只能枚举世界生成器**位置固定且可按种子推算**的箱子——完整支持列表参见[箱子战利品预览](features/chest-loot-preview.md)。

    村庄、海底废墟、林地府邸、远古城市、废弃矿井、试炼密室、怪物房间等结构暂不显示「战利品」入口；此外，被数据包修改的战利品表也不做预测。

## 数据迁移与外观

??? question "能从 Xaero 或 VoxelMap 迁移数据吗？"
    **可以。**

    - **路径点**：支持从 Xaero's Minimap 与 VoxelMap 一键导入，重复项自动跳过，原文件保持不变；
    - **世界地图地形**：在全屏地图的操作工具中选择导入入口，可读取 Xaero 世界地图数据并按维度合并至尚无本模组捕获的区域——详见[绘图与导出](features/drawings-export.md)。

??? question "可以更换地图 UI 皮肤吗？"
    **可以。** 工具栏图标与小地图边框遵循普通 Minecraft 资源包规范，Xaero UI 资源包中的兼容素材亦可直接使用。支持的路径与限制参见 [UI 资源包说明](https://github.com/Conflux-Union/conflux-map/blob/master/docs/reference-specs/ui-resource-packs.md)。

## 服务端管控与网页地图

??? question "服务端可以禁用部分客户端功能吗？"
    **可以。** 通过服务端组件（或按[网络协议](technical/protocol.md)实现的第三方插件），服主可针对配合客户端逐项关闭小地图、世界地图、路径点、种子预测或实体雷达。未安装组件的服务端不会施加任何限制。

??? question "如何安全地将内置网页地图公开给玩家访问？"
    网页地图默认仅监听本地 `127.0.0.1:8123`。如需公开访问，请使用 Nginx / Caddy 等将其置于 **HTTPS 反向代理**之后，并确保代理保留了原始 `Host` 请求头。
