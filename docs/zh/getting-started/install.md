# 安装

从 [Releases](https://github.com/Conflux-Union/conflux-map/releases) 页面下载对应
Minecraft 版本的 JAR,与 [Fabric API](https://modrinth.com/mod/fabric-api)
一同放入 `mods/` 目录。自行构建的方法参见[参与开发](../technical/developing.md)。

[MaliLib](https://modrinth.com/mod/malilib) 为可选依赖。安装后按键支持多键组合,
Conflux Map 也会出现在 MaliLib 的 A+C 设置切换界面中。

小地图、世界地图、路径点、绘图与导出功能仅依赖客户端。全服地图同步、共享路径点、
区块加载等级与网页地图需要[服务端组件](../technical/server-companion.md)。
