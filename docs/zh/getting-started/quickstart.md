# 快速上手

完成[安装](install.md)后，无需任何额外配置即可直接进入游戏使用。以下是一套最常用的基础操作流程：

## 核心操作流

1. **控制小地图与全屏地图**
   - 按 `H` 开启或关闭 HUD 小地图，按 `]` 循环切换小地图缩放。
   - 按 `M` 打开全屏世界地图，使用鼠标滚轮以光标为中心缩放，按住左键拖动平移。
   - 按 `Y` 快速切换图层视图（自动 / 地表或顶层 / 当前高度 / 固定高度）。

2. **创建与管理路径点**
   - 按 `B` 在当前脚下位置快速新建路径点，或在全屏地图上**右键任意位置**创建。
   - 按 `U` 打开路径点列表进行搜索、分组或批量管理；按 `J` 快速显示/隐藏本地路径点。

3. **地图传送**
   - 在全屏地图上右键路径点或任意位置并选择**传送**（需服务器允许或单人开启作弊），默认支持跨维度目标。

4. **开启地图补全（种子预测）**
   - 当客户端获取到世界种子（单人自动获取，或服务器下发/本地配置）后，未探索区域会立即显示预测地形。
   - 按 `P` 在「**全部预测 / 仅已生成 / 仅已探索**」三种显示范围之间切换；按 `F9` 强制刷新预测瓦片。

5. **打开设置**
   - 按 `,` 打开 Conflux Map 设置界面，所有外观、图层、雷达与补全选项均**即时生效**。

!!! tip "从 Xaero / VoxelMap 迁移？"
    如果你之前使用过 Xaero's Minimap、Xaero's World Map 或 VoxelMap，可以在路径点界面直接一键导入旧路径点，并在全屏地图的操作工具中导入 Xaero 世界地图缓存。详见 [路径点](../features/waypoints.md) 与 [绘图与导出](../features/drawings-export.md)。
