# 快速上手

1. **安装**:按[安装](install.md)说明,把对应 Minecraft 版本的 JAR 与
   Fabric API 放入 `mods/`。服务端组件是可选的——以下功能客户端独立可用。
2. **打开世界地图**:按 `M`。`H` 开关小地图;`]` 循环小地图缩放,全屏地图用滚轮。
3. **放置路径点**:按 `B` 在当前位置创建,或右键地图。`U` 打开路径点列表。
4. **传送到路径点**:右键地图上的路径点并选择传送——服务器允许时可用,
   跨维度目标同样支持。
5. 随着探索,地图逐渐填充;获取世界种子后,未探索区域会显示预测地形
   (`P` 切换范围,`F9` 强制刷新)。

以上按键均可在原版控制设置中修改——参见[按键绑定](../reference/keybinds.md),
全部选项见[配置参考](../config/index.md)。
