## 1. 审计与基线对拍方法论说明
- **基线来源**: 直接通过完全隔离的 `upstream/master` 未动分毫的原生源码（`master_cfxOverviewHeightsImpl`）在内存中真实求值作为客观对照，**彻底剔除任何手写模拟/简化伪基准**。
- **海岸带保护 (Waterline Protection)**: 凡跨越海平面（$61 \le Y \le 65$）的世界网格强制进入精密计算，确保水陆边界与群系色彩零撕裂。
- **无偏双线性插值 (Unbiased Interpolation Rounding)**: 宏观与局部子网格双线性插值采用无偏对称舍入（`floordiv(val + half, divisor)`），彻底消除了因整数向下硬截断带来的系统性负向高度塌陷。
- **构建系统与验证**: Gradle 任务 `testNativePurity` 真正编译并执行本地位置纯性断言（多形状重叠区 0 mismatch）；ASan/UBSan 全程零报错。
- **全量 300 案例覆盖 (5 x 5 x 3 x 4 笛卡尔积)**:
  - 5 种子: `146008555LL`, `123456789LL`, `987654321LL`, `2026110701ULL`, `2026110702ULL`
  - 5 位置: `(0, 0)`, `(5M, 5M)`, `(-3M, 2.5M)`, `(30M, 30M)`, `(-25M, -10M)`
  - 3 步长: `Stride 1`, `Stride 2`, `Stride 4`
  - 4 几何相位:
    - `Clean (mod 4 == 0)`: `(0, 0, 256, 256)`
    - `OddWidth`: `(1, 1, 257, 257)`
    - `StandardTile (生产标准)`: `(-1, -1, 258, 258)`
    - `OffPhase`: `(2, 3, 258, 258)`
